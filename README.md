<h1 align="center">Dossiê Arcano: Soren <s>Vaelor</s> Alkahest</h1>

<p align="center"><i>Nihil ex nihilo. Omnia mutantur. Anima est pretium.</i></p>

O site de um personagem de RPG: Soren, tiefling alquimista, nascido humano na casta mais baixa de um clã que mede o valor de uma vida pela densidade da alma. Aos sete anos, o patriarca Lazare Vaelor pagou um pacto infernal com as almas dos pais dele. Soren descobriu aos dezessete, riscou o sobrenome do grimório e foi embora.

O site conta essa história e acompanha a campanha, sessão a sessão, pela voz do próprio Soren.

---

## As duas lentes

Tudo no site existe em duas versões. A **Máscara Racional** é o que Soren mostra ao mundo: frio, elitista, gótico, em brasa. Ao **tocar o colar** dos pais, a tela é tomada pela luz do cristal e entra a **Ressonância**, com o que ele reprime.

## O Diário e o Compêndio

São dois livros diferentes. O **Diário** é cronológico: o que aconteceu em cada sessão. O **Compêndio** é de consulta: o que Soren estudou e cataloga, organizado em abas de índice.

      Campos que ele ainda não descobriu aparecem como <b>borrões de tinta</b>. Os dois livros são escritos em Markdown, um arquivo por entrada, com algumas marcações próprias:

| Escreva | Vira |
|---|---|
| `\|\|texto\|\|` | tinta invisível, rasurada na Máscara e revelada pelo colar |
| `![legenda](/assets/diario/x.webp)` | um esboço colado na página, com legenda |
| `[[slug]]` | link para um verbete do compêndio (ou "ainda não escrito", riscado) |

## Som

A trilha tem dois temas, um por lente: **House of Ashen Vows** na Máscara e **Lost Lullaby** na Ressonância. Ao tocar o colar, uma faixa se dissolve na outra. Há efeitos para o colar, para as transições de página (chamas ou magia), para a capa e as páginas do diário e para os selos do Atlas. A sineta pendurada ao lado do colar silencia tudo.

Músicas e efeitos foram gerados no ElevenLabs. As artes foram geradas no Gemini a partir das originais do personagem.

## Rodando

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # gera dist/
npm test        # testes do frontmatter e do Markdown (tinta, esboços, links)
```

Feito em React 19, Vite 6, React Router 7 e Tailwind CSS 3.4, com `marked` para o Markdown. No computador, cada página cabe inteira na tela; no celular, o site volta a rolar.

### Estrutura

```
src/
  pages/        uma página por seção (Matriz, Crônica, Casa Vaelor, Atlas, Diário, Compêndio)
  components/   barra superior, pingente do colar, sineta, partículas de fundo, transições, ornamentos
  data/         a lore: personagens, castas, atos, mapas
  diario/       entradas do diário, uma por .md
  compendio/    verbetes do compêndio, em alquimia/, pessoas/, criaturas/ e pacto/
  lib/          leitura do Markdown, compêndio, diário e som
public/
  assets/       artes, texturas, brasões, iluminuras, esboços
  sons/         efeitos sonoros
  musica/       os dois temas
tools/
  esboco_lapis.py   transforma uma arte em desenho a lápis sobre pergaminho
```

## Escrevendo no Diário

Crie `src/diario/<slug>.md`. O nome do arquivo vira a URL (`/diario/<slug>`):

```md
---
session: Sessão 01
date: 2026-11-08
title: Título da Entrada
location: Onde a sessão aconteceu
---

Texto em Markdown, na voz do Soren. *itálico*, **negrito**, > citações, listas, ---

O que ele escreve e ||o que ele não admite|| fica na mesma frase.
```

- `date` define a ordem no livro e no sumário. Aceita `2026-11-08`, `08-11-2026` ou `08/11/2026`. Entradas sem data (ou com `00-00-0000`) vão para o fim do livro, ordenadas pela `session`. O link `/diario/<slug>` abre o livro direto na entrada.
- `location` é opcional e aparece abaixo da data, no topo da entrada.
- O diário é paginado automaticamente; uma entrada longa ocupa quantas páginas precisar.
- Imagens vão em `public/assets/diario/`. Elas aparecem sempre inteiras numa página só (no máximo cerca de 55% da altura).

## Escrevendo no Compêndio

Crie `src/compendio/<seção>/<slug>.md`, com `<seção>` sendo `alquimia`, `pessoas`, `criaturas` ou `pacto`. A URL fica `/compendio/<seção>/<slug>`.

```md
---
title: Raiz de Mandrágora
tipo: Planta
raridade: Rara
efeito: Sono profundo
conhecimento: 2
imagem: /assets/compendio/mandragora.webp
ver: solvente-alkahest, diabrete
visto: sessao-03
---

Anotações do Soren. Aceita ||tinta invisível||, ![esboços](/assets/...) e [[links-para-verbetes]].
```

Campos da ficha por seção. Os que faltarem aparecem como borrão de tinta, ou seja, Soren ainda não descobriu:

| Seção | Campos |
|---|---|
| alquimia | `tipo`, `raridade`, `efeito`, `ingredientes`, `preparo`, `onde` |
| pessoas | `relacao`, `faccao`, `situacao`, `onde`, mais `casta` (Éter, Mercúrio, Enxofre, Cinza), `alma` (0 a 100), `veredito` (frase na Máscara) e `sentimento` (frase na Ressonância) |
| criaturas | `tipo`, `habitat`, `perigo`, `fraquezas`, `partes` |
| pacto | `status` (`confirmada`, `hipótese`, `descartada`), `fonte` |

Comuns a todas:
- `conhecimento`: de 0 a 4, aparece como ●●○○.
- `imagem`: a gravura. Com ela, o verbete vira uma **prancha**: o desenho ocupa a página da esquerda e a ficha vai para a direita, junto das anotações.
- `ver`: slugs de outros verbetes, separados por vírgula.
- `visto`: slugs de entradas do diário, separados por vírgula.
- `selado: true`: a página fica lacrada com cera e só abre na Ressonância.

`[[slug]]` (ou `[[slug|texto]]`) funciona nas anotações, nos campos da ficha e no diário.

Para fazer uma versão "desenho a lápis" de uma arte existente (precisa de Python com Pillow e NumPy):

```bash
python tools/esboco_lapis.py public/assets/villain.jpg public/assets/textura-pergaminho.webp public/assets/compendio/lazare-esboco.webp
```

### Quadro de investigação

O link "Desdobrar o quadro de investigação", no índice de O Pacto, abre `/compendio/pacto/quadro`.
- Cada verbete do Pacto vira um cartão preso com alfinete de cera, marcado pelo `status`.
- Um fio liga a pista a cada verbete do campo `ver`. Verbetes de outras seções entram como cartões de evidência.
- Fios de pistas descartadas ficam apagados. Na Ressonância, os fios viram luz.
- Os cartões se distribuem sozinhos numa elipse. Para fixar a posição, use `quadro: x, y` (em %, por exemplo `quadro: 20, 35`).
- `quadro` é um nome reservado: não crie um verbete com esse slug no Pacto.
